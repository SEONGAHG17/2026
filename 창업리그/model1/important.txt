1. 패키지 빌드 최초 1회

colcon build --packages-select concert_model1
source install/setup.bash


2. 통합 런치 파일 실행 

ros2 launch concert_model1 model1_pipeline_launch.py

^^
이 명령어를 치면 백그라운드에서 RTAB-Map이 드론의 위치를 추정하고, 
그 지도를 OctoMap이 받아 Voxel(3차원 격자) 구조로 실시간 변환하기 시작합니다. 
RViz 창을 띄워 지도가 그려지는 모습을 눈으로 확인할 수도 있습니다.





# 드론이 무대 전체를 충분히 스캔했다고 판단되면, 메모리에 쌓인 3차원 공간 격자를 파일로 확정 지어 저장합니다.

3. OctoMap 저장 명령어 입력
3. 새로운 터미널을 열고 아래 명령어를 입력하여 현재 만들어진 맵을 .bt 확장자로 저장합니다.

ros2 run octomap_server octomap_saver ~/concert_model1/maps/concert_stage.bt


4. 결과물 확인
4. 지정해 둔 maps/ 폴더 안에 concert_stage.bt 파일이 생성된 것을 볼 수 있습니다

5. concert_stage.bt 파일이 바로 모델 1이 만들어낸 최종 아웃풋
